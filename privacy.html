Privacy Policy - Hermes Agent

Last updated: October 20, 2026

Hermes Agent is a personal assistant app used only by its owner, Luis Galaviz. It is not available to the public.

What data it accesses

With the owner's permission through Google sign-in, Hermes Agent accesses the owner's own Gmail, Google Calendar, Google Drive, Docs, Sheets and Contacts to read, organize and draft or send messages on the owner's behalf.

How data is used and stored

Data is used only to perform tasks the owner requests. It is processed on the owner's private server and is not sold, shared with third parties for advertising, or used for any other purpose.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at https://myaccount.google.com/permissions.
